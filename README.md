# LandMarkVLN · WACV 2027

Project homepage: **https://realjoshqsun.github.io/landmark-vln/**

Built from [Roman Hauksson’s Academic Project Astro Template](https://github.com/RomanHauksson/academic-project-astro-template). The original template attribution is retained in the site footer. The template is licensed under CC BY-SA 4.0; paper content and figures belong to their authors.

## Edit and preview

Requires Node.js 24 or later.

```sh
npm ci
npm run dev
```

Edit `src/paper.mdx` for the content, `src/styles/project.css` for project styling, and `src/components/Header.astro` for the title block. Paper figures are in `src/assets/paper/`.

```sh
npm run build
npm run preview
```

The built static site is in `dist/`. The included GitHub Pages workflow handles the site URL and repository base path automatically when Pages is configured to use GitHub Actions.

The Code button links to the official [LandMarkVLN repository](https://github.com/realjoshqsun/LandMarkVLN), which provides CPU analysis code and frozen model measurements. Paper PDF and raw dataset download links remain omitted. This repository contains the project website source. Author order follows the existing homepage’s verified publication record; affiliations are omitted until confirmed. No experiment output is fabricated. The comparison slider shows two attribution overlays from the paper’s Figure 1, not an original-versus-edited simulation.
